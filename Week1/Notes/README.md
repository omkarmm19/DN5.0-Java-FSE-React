# Week 1 Notes

## Design Patterns

### Singleton Pattern
- Ensures only one instance of a class exists.
- Provides a global access point to the instance.

### Factory Method Pattern
- Creates objects without exposing creation logic.
- Promotes loose coupling and scalability.

---

## DSA

### Linear Search
- Time Complexity: O(n)
- Checks elements sequentially.

### Binary Search
- Time Complexity: O(log n)
- Requires sorted data.

### Recursion
- Function calls itself.
- Used in Financial Forecasting exercise.

---

## PL/SQL

### Control Structures
- IF-THEN
- IF-THEN-ELSE
- Loops
- Conditional execution

### Stored Procedures
- Reusable PL/SQL program units.
- Improve modularity and maintainability.

---

## JUnit

### Assertions
- assertEquals()
- assertTrue()
- assertFalse()
- assertNotNull()

### AAA Pattern
- Arrange
- Act
- Assert
